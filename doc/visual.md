# Physarum Oracle 视觉方向

## 情绪承诺

像在暗室显微镜下亲手喂养一张会思考的道路图：幽暗、精密、不断涌现。

## 画面系统

- 背景：`#050806`。
- 网络：原作单通道 trail 经青白色映射显示，核心高光接近白色，外围为磷绿色。
- 标题：窄体大写、左上不超过视口 25%。
- UI：无面板外框，细线与数字直接悬浮，避免遮挡模拟。
- 功能图标：统一线性 SVG；禁止 Emoji。

## 动效

网络保持原 shader 的连续扩散和代理沉积。首次进入由幽灵手指真实注入一段弧线；HUD 数字更新不抢夺视觉焦点。结算以轻微模糊背景和 220 ms 淡入出现。

## 反模式

不使用设备外框、视频播放图标、厚重玻璃卡片、常驻操作说明或与模拟无关的爆炸碎片。
