# Physarum Oracle 视觉方向

## 情绪承诺

像在暗室显微镜下亲手喂养一张会思考的道路图：幽暗、精密、不断涌现。

## 画面系统

- 背景：`#050806`。
- 网络：原作单通道 trail 经青白色映射显示，核心高光接近白色，外围为磷绿色。
- 标题：窄体大写、左上不超过视口 25%。
- 信标：直径 18 px 的双环节点，未连接时只有磷绿细线，连接后出现实心核心和外扩波纹。
- UI：无面板外框，右上只显示 `LINKS 1/4` 与当前法则，避免遮挡模拟。
- 功能图标：统一线性 SVG；禁止 Emoji。

## 动效

网络保持原 shader 的连续扩散和代理沉积。首次进入由幽灵手指真实注入一段弧线；触达信标时外环在 360 ms 内扩散并播放短音。第四个节点连通后网络继续生长 1.2 秒，结算以轻微模糊背景和 220 ms 淡入出现。

## 反模式

不使用设备外框、视频播放图标、厚重玻璃卡片、常驻操作说明或与模拟无关的爆炸碎片。
