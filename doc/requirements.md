# Physarum Oracle 需求文档

## 1. Overview

一款 24 秒即开即玩的黏菌运输网络视觉体验：玩家在活体粒子场中划入化学引导线，观察数十万代理自行汇聚成有机网络。

## 2. Visual Design

全屏黑绿实验场，保留原作高密度白色 Physarum 纤维；标题置于上方安全区，HUD 仅显示倒计时与生长度，结算浮在网络上方。移动端以 390×844 为主，兼容 320×568。

## 3. Game Mechanics

- 初始粒子密度为每像素 0.22，移动步长 2 px，传感距离 18 px。
- 每帧执行方向感知、代理移动、化学沉积、扩散衰减和显示五个 GPU pass。
- 单指轨迹以 28 px 直径注入吸引剂。
- 双指触发后在 Fibers、Fingerprint、Honeycomb 三组原作参数间切换并重置网络。
- 24 秒读取 24×24 像素场的覆盖率，转换为 0–999 连通度。

## 4. Controls

- Pointer/Touch：单指按下与拖动注入吸引剂。
- Touch：双指同时接触切换生长法则。
- Keyboard：R 重置。

## 5. Win / Lose Conditions

无失败；24 秒后暂停并显示连通度。玩家可点击“再生长一次”开启新一轮。

## 6. Sound Effects

- 注入：220–360 Hz 正弦波，60 ms，限制为每 120 ms 一次。
- 切换法则：330/495 Hz 双音，120 ms。
- 结算：220/330/440 Hz 三音上行，每音 120 ms。
