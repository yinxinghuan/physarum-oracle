# Physarum Oracle 需求文档

## 1. Overview

一款自定节奏的黏菌运输网络视觉体验：玩家在活体粒子场中划入化学引导线，让数十万代理依次连接四个发光信标。

## 2. Visual Design

全屏黑绿实验场保留原作高密度白色 Physarum 纤维；四个信标分布在主要触摸区域，标题置于上方安全区，HUD 仅显示连通数与当前生长法则。移动端以 390×844 为主，兼容 320×568。

## 3. Game Mechanics

- 初始粒子密度为每像素 0.22，移动步长 2 px，传感距离 18 px。
- 每帧执行方向感知、代理移动、化学沉积、扩散衰减和显示五个 GPU pass。
- 单指轨迹以 28 px 直径注入吸引剂。
- 双指触发后在 Fibers、Fingerprint、Honeycomb 三组原作参数间切换并重置网络。
- 四个信标位于归一化坐标 `(0.24,0.38)`、`(0.76,0.33)`、`(0.68,0.68)`、`(0.28,0.73)`，根信标初始点亮。
- 单指轨迹进入信标 42 px 半径即完成一次连接；四个全部点亮后继续生长 1.2 秒再结算。
- 路径效率为 `min(100, round(100 × 520 / max(520, 轨迹距离)))`，只用于完成评价。

## 4. Controls

- Pointer/Touch：单指按下与拖动注入吸引剂并连接信标。
- Touch：双指同时接触切换生长法则。
- Keyboard：R 重置。

## 5. Win / Lose Conditions

无失败，也没有倒计时。四个信标全部连通后显示 100% 连通与路径效率；玩家可点击“再生长一次”开启新网络。

## 6. Sound Effects

- 注入：220–360 Hz 正弦波，60 ms，限制为每 130 ms 一次。
- 连接节点：从 280 Hz 起按节点序号增加 80 Hz，120 ms。
- 切换法则：330/495 Hz 双音，120 ms。
- 完成网络：220/330/440 Hz 三音上行，每音 120–180 ms。
